## 🚀 Featured Projects

### [SpendWise](https://github.com/snehaldevrani/SpendWise) — AI-Powered Finance Tracker &nbsp; [**Live ↗**](https://spendwise-web-nine.vercel.app)

Full-stack personal finance app that parses Indian bank statements, detects subscription leaks, and answers spending questions via Gemini AI.

- **Stack:** NestJS · Next.js 15 · TypeScript · PostgreSQL · pgvector · BullMQ · Redis · Docker
- **Auth:** JWT httpOnly cookies · Google OAuth · bcrypt · Redis-backed rate limiting
- **AI:** RAG pipeline with 768-dim pgvector HNSW search · Gemini 2.5 Flash
- **Quality:** 94 tests · GitHub Actions CI/CD · Live on Vercel + Render

---

### [LiteStore](https://github.com/snehaldevrani/LiteStore) — Redis-Inspired KV Server

Key-value store built from scratch in Python. Replaced Redis's probabilistic TTL sampling with a deterministic timing wheel.

- **357,000 ops/sec** on EC2
- Custom RESP protocol · In-memory hash table · Persistence via AOF
- Deterministic TTL eviction (timing wheel vs Redis's probabilistic approach)

### [Real-Time Data Pipeline](https://github.com/snehaldevrani/realtime-market-surveillance)

Fault-tolerant async pipeline for high-volume market data ingestion.

- **2.4M+ API requests/day** across 300+ credentials
- 99.9% uptime · Adaptive rate limiting · Circuit breakers · systemd supervision
- Built with Python asyncio · aiohttp · SQLite
